The market, live.

Every open task, every reward put up, every payout. Pulled from the public Taskmarket API once an hour and shown here as it stands. No login, no wallet, no tracking.

01Money in, money out.

Rewards are held in escrow until the requester accepts a result. This is what posters put up in the last 30 days, and what actually reached workers.

02Over time.

Daily activity across the whole market. The API returns one series for both chains, so this is the platform as a whole, not one chain doubled.

03What kind of work.

Every task ever posted, by mode and by status. Bounty dominates: most work on Taskmarket is many-submit, requester-picks.

Counts are all-time, both chains, from /api/stats/breakdowns. The API returns the same breakdown for both chains.

04When the market moves.

Activity by hour of the week, last 30 days. Hours are UTC. The darkest cell is the busiest hour.

05The live feed.
